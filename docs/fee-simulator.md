# 料金シミュレーション・応援数の表示

2026-10-07。対象：Caresの事業所詳細 `/directory/[id]`、公式投稿ページ `/facility/[id]`。

## 計算の流れ

サービス種別から公定単価の候補を絞り、介護度・事業所の規模／提供体制・時間区分・回数・所在地の地域区分を選ぶ。時間の異なる利用パターンを追加できる。週の回数は4.3倍を四捨五入した月の目安で、月の回数を直接指定すれば正確な予定回数を使える。未確認の規模・時間は推定せず選択を求める。山形県／山形市は公表地域表の「その他」を初期表示し、変更可能。

介護保険の自己負担と `facility_portal_fees` の公開自費料金を合算する。公定単価を使う場合、事業所が登録した `insurance_estimate` は二重計上しない。

- 自費は登録済みの単位（日、回、食、時間、月、一括）を尊重。日数と回数を分け、食数は初期値1食／日。
- 食費などの数量は項目別に変更可能。0回も指定でき、既定の数量に戻せる。金額そのものは事業所設定を使用。
- 月額は固定、初期費用／一括は月額に含めない。金額幅、介護度別、任意項目を保持。
- 不明な金額・不正な数量・料金取得エラーを0円として総額に混ぜない。
- 金額換算はサービス単位数を月合計し地域単価を掛けて円未満切捨て、保険給付を切捨てて残額を自己負担にする。
- 処遇改善は自費を除く同種別の選択済み単位数に率を掛けて四捨五入。月額加算は回数倍しない。
- 通所の大規模区分は給付管理用単位数を別途使用。限度額超過は全額自己負担の割当確認が必要なため総額を確定表示しない。他サービス利用単位も入力可能。
- 処遇改善未選択は「加算未確認の小計」、自費未公開は「介護保険分のみ」と表示。
- 条件・算式・除外事項・出典を含めてコピー可能。入力はブラウザー内のみで、利用者情報を保存・送信しない。

## 公定単価の範囲

厚労省の2026年5月25日確定版、2026年6月施行の標準基本報酬459件、表示する加算50件。2026年6月〜2027年3月の試算を対象とする。訪問介護、訪問入浴、訪問看護、訪問リハ、通所介護、通所リハ、地域密着型通所介護の7種別。

通所介護・地域密着型通所介護は入浴、個別機能訓練Ⅰ／Ⅱ、科学的介護、サービス提供体制、処遇改善を選択可能。択一の加算はselectで一つだけ選び、個別機能訓練Ⅱの前提を確認。処遇改善は7種別の令和8年6月版を収載。

その他のサービスは既存の事業所登録料金を使う。全サービスや国保連請求を自動算定するものではない。予防・総合事業、共生型、訪問介護の身体＋生活の組合せや20分未満、時間帯加算、特殊な減算、一覧にない加算、公費助成、高額介護サービス費、限度額超過分の配分は未対応。訪問看護・リハの20分単位は1回の算定単位として回数を指定し、適用要件・回数制限は事業所に確認する。

## 応援数

DBの上限なし整数文字列と正確な件数は保持。カード・地図・詳細の大きな表示は万／億／兆等に短縮し、非常に大きい値は指数表示にする。浮動小数点には変換しない。詳細で「正確な累計を見る」を開くと全桁を折り返して表示。カードはtitle／アクセシブルラベルにも正確な件数を保持する。地図ではサービス種別を別の行へ分離し、応援バッジを折り返さない。
